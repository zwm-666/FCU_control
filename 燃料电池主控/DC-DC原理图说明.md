## 1. 系统总览

```
输入（12V / 24V）
      │
      ▼
 ┌────────────────────────────────────────────────────┐
 │                    Board2（300boost）               │
 │                                                    │
 │  CN1(12V/24V输入)                                  │
 │      │                                             │
 │      ├── L3/L4 磁珠 ── 主功率回路                   │
 │      │       │                                     │
 │      │   Q3 / Q5 (HB10N200S NMOS)                 │
 │      │       │  ← U1(UCC27524DR) 栅极驱动           │
 │      │       │  ← U25(MX74700T) 浪涌抑制            │
 │      │       │                                     │
 │      │   D1(SL20100DS) 整流                        │
 │      │       │                                     │
 │      │   C14/C17/C22 输出滤波                       │
 │      │       │                                     │
 │  U2(INA199) 输入电流采样    U3(INA199) 输出电流采样  │
 │      │                                             │
 │      ▼                                 ▼           │
 │  IN_I (至FCU ADC)              OUT_I (至FCU ADC)   │
 │                                                    │
 │  U9(TX4139) PWM控制 ← FB反馈 ← R12/R13分压         │
 │      │         ← ILIM 限流 ← R11(30mΩ)            │

 └────────────────────────────────────────────────────┘
```

**功能**：将 12V 或 24V 输入升压至 48V，最大功率约 300W。

## 2. P1 — 主功率回路

### 2.1 栅极驱动（U1 UCC27524DR）

**器件**：`U1` — UCC27524DR（双路 5A 栅极驱动器，SOP-8）

| 引脚 | 名称 | 连接 | 说明 |
|------|------|------|------|
| 1 | ENA | PWM | 通道 A 使能输入（来自控制器） |
| 2 | INA | PWM | 通道 A 信号输入 |
| 3 | GND | PGND | 功率地 |
| 4 | INB | PWM | 通道 B 信号输入 |
| 5 | OUTB | → Q5 Gate | 通道 B 驱动输出 |
| 6 | VDD | 13V+ | 驱动器供电（13V 偏置） |
| 7 | OUTA | → Q3 Gate | 通道 A 驱动输出 |
| 8 | ENB | PWM | 通道 B 使能输入 |

> **说明**：UCC27524 为非反相双路驱动器，峰值输出电流 ±5A，适用于高频升压拓扑。  
> VDD 供电来自 13V 辅助电源，确保 NMOS 完全导通。

---

### 2.2 主开关管（Q3 / Q5 HB10N200S）

**器件**：`Q3`、`Q5` — HB10N200S（N-MOS，200V / 10A）

| 参数 | 值 |
|------|-----|
| 类型 | N-MOS |
| 耐压 Vds | 200V |
| 电流 Id | 10A |
| 封装 | — |
| Gate 驱动 | U1 OUTA（Q3）/ U1 OUTB（Q5） |

> **拓扑**：两管并联（或交错并联），提升电流能力，降低开关损耗。  
> **保护**：D5（ES3JB）作为体二极管补偿或死区续流保护。

### 2.4 电流采样（U2 / U3 INA199A1DCKR）

**器件**：`U2`、`U3` — INA199A1DCKR（电流检测放大器，增益 ×100，SC-70-6）

#### U2 — 输入电流采样

| 引脚 | 名称 | 连接 |
|------|------|------|
| 1 | REF | GND |
| 2 | GND | GND |
| 3 | V+ | 3.3V |
| 4 | IN+ | IN_I+（采样电阻正端） |
| 5 | IN- | IN_I-（采样电阻负端） |
| 6 | OUT | IN_I（→ FCU ADC） |

**采样电阻**：`R1` = 2 mΩ（输入侧）

```
计算：INA199A1 增益 = 100 V/V
      满量程电流 = 35A（额定）
      差分电压 = 35A × 2mΩ = 70mV
      输出电压 = 70mV × 100 = 7.0V  ← 注意需核实是否超出 3.3V ADC 范围
```

#### U3 — 输出电流采样

结构与 U2 相同，采样输出电流。

| 引脚 | 名称 | 连接 |
|------|------|------|
| 4 | IN+ | OUT_I+ |
| 5 | IN- | OUT_I- |
| 6 | OUT | OUT_I（→ FCU ADC） |

**采样电阻**：`R18` = 5 mΩ（输出侧）

**滤波**：C27、C28 各 100nF（U2/U3 输出滤波）

### 3.4 反馈网络

输出电压由 R12 / R13 分压后接入 U9 的 FB 引脚。

| 器件 | 阻值 | 说明 |
|------|------|------|
| R12 | 300 kΩ | FB 上分压电阻 |
| R13 | 21.5 kΩ | FB 下分压电阻 |
| C32 | 47 pF | FB 补偿电容（相位补偿） |

```
输出电压计算（以 TX4139 内部参考电压 Vref = 1.25V 为例）：

  Vout = Vref × (1 + R12/R13)
       = 1.25 × (1 + 300k/21.5k)
       = 1.25 × 14.95
       ≈ 18.7V   ← 实际输出 48V，请以数据手册核对 Vref 值

  ⚠️ 若 Vout 目标为 48V：
     R12/R13 = (48/Vref - 1) = (48/1.25 - 1) ≈ 37.4
     → R12 = 300kΩ 时，R13 ≈ 8.02kΩ（需核实 R13 实际为 21.5kΩ 对应的目标电压）
```

> ⚠️ **待确认**：TX4139 的内部参考电压及 R12/R13 实际对应的输出电压目标，请查阅数据手册核实。

**电流限制设定**：

| 器件 | 参数 | 说明 |
|------|------|------|
| R11 | 30 mΩ | ILIM 采样电阻 |
| R10 | 10 Ω | ILIM 引脚串联保护 |

```
峰值限流（以典型阈值 V_ILIM = 100mV 为例）：
  I_peak = V_ILIM / R11 = 100mV / 30mΩ ≈ 3.33A
  ← 实际阈值请查阅 TX4139 数据手册
```
