# FCU 普通串口协议说明

本文档描述 STM32 FCU 通过 RS485 物理层承载的普通 UART 二进制帧。当前固件不再使用 Modbus RTU；上电初始化后会主动周期上报状态帧，也可接收上位机控制帧。

## 串口参数

| 参数 | 值 |
|---|---:|
| 波特率 | 9600 |
| 数据位 | 8 |
| 校验 | None |
| 停止位 | 1 |

## 帧格式

固定 16 字节：

```text
AA 55 ID0 ID1 ID2 ID3 LEN DATA0 DATA1 DATA2 DATA3 DATA4 DATA5 DATA6 DATA7 SUM
```

| 字段 | 长度 | 说明 |
|---|---:|---|
| 帧头 | 2 | 固定 `AA 55` |
| ID | 4 | 原 CAN 扩展帧 ID，小端传输 |
| LEN | 1 | 固定 `08` |
| DATA | 8 | 沿用原 CAN payload |
| SUM | 1 | 从 `ID0` 到 `DATA7` 所有字节累加，取低 8 位 |

## 帧 ID

| ID | 方向 | 周期 | 含义 |
|---:|---|---:|---|
| `0x18FF01F0` | FCU -> 上位机 | 100 ms | 状态与心跳 |
| `0x18FF02F0` | FCU -> 上位机 | 100 ms | 电压电流数据 |
| `0x18FF03F0` | FCU -> 上位机 | 100 ms | 温度与压力数据 |
| `0x18FF04F0` | FCU -> 上位机 | 100 ms | 外设状态与故障码 |
| `0x18FF10A0` | 上位机 -> FCU | 按需/周期 | 控制指令 |

payload 定义沿用 `FCU_上位机_CAN通信协议_V1.1.md`。

## 示例

状态帧 payload：

```text
12 02 00 00 00 00 00 00
```

串口帧：

```text
AA 55 F0 01 FF 18 08 12 02 00 00 00 00 00 00 24
```

控制帧 payload：

```text
04 19 50 E0 01 64 00 00
```

串口帧：

```text
AA 55 A0 10 FF 18 08 04 19 50 E0 01 64 00 00 81
```
