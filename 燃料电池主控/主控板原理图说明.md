## 4. ROM 存储器（EEPROM）

**器件**：`U2` — 24C02C-E/P（I²C，256×8 bit = 2 Kbit）

| U2 引脚 | 名称 | 连接 |
|---------|------|------|
| 1 | A0 | GND（地址 bit0 = 0） |
| 2 | A1 | GND（地址 bit1 = 0） |
| 3 | A2 | GND（地址 bit2 = 0） |
| 4 | Vss | GND |
| 5 | SDA | IIC-SDA-24C02 |
| 6 | SCL | IIC-SCL-24C02 |
| 7 | WP | GND（写保护禁用） |
| 8 | Vcc | 3.3V |

**I²C 上拉**：R3 = 4.7 kΩ（SCL），R4 = 4.7 kΩ（SDA），上拉至 3.3V  
**去耦电容**：C3 = 100 nF（Vcc 旁路）  
**I²C 器件地址**：`0x50`（A2:A1:A0 = 000）  
**STM32 连接**：`PB6`（IIC-SCL）、`PB7`（IIC-SDA）

## 9. 高边驱动（阀体控制）

三路高边驱动均采用相同电路结构：**MCU GPIO → 光耦隔离（TLP181）→ P-MOS 栅极 → 24V 高边输出**。

### 9.1 电路结构（以某一路高边驱动为例）

```
STM32 MOUTx(GPIO)
    │
    └──[R76 510Ω]──▶ U16(TLP181 光耦)
                          │
                          ▼（光耦输出侧）
                    [R94 10kΩ 上拉至 24V]
                          │
                    Q3(IRFR5305 P-MOS) Gate
                          │
                    [R86 47kΩ G-S 下拉]
                          │
                    Q3 Drain ─── 24V 高边输出（MOUTx）
                    Q3 Source ── 24V
                          │
                    D13(SS36) 续流二极管（G-S 反向保护）
```

### 9.2 三路驱动汇总

| 信号名 | STM32 引脚 | 光耦器件 | MOS 器件 | 续流二极管 | 输出功能 |
|--------|-----------|---------|---------|-----------|---------|
| MOUT1 | PA0（pin 10） | U16 TLP181 | Q3 IRFR5305 | D13 SS36 | 进氢阀（24V，≤2A） |
| MOUT2 | PA1（pin 11） | U14 TLP181 | Q1 IRFR5305 | D11 SS36 | 排氢阀（24V，≤2A） |
| MOUT3 | PB8（pin 45） | TLP181（位号待确认） | Q6 SUD50P10-43L-TP（高边） | D10 SS310 | 风扇电源高边控制 |

> **控制逻辑**：MCU 输出高电平 → 光耦导通 → MOS 栅极拉低 → P-MOS 导通 → 阀体通电开启。  
> **支持模式**：GPIO 开关模式 / PWM 脉冲吹扫模式。

## 10. 48V 风扇控制

**器件**：`Q6` — SUD50P10-43L-TP（P-MOS，48V/43A）

### 控制链路

```
STM32 PB8(MOUT3, pin 45)
    │
      └──[R199 1kΩ]──▶ TLP181 光耦（位号待确认）
                          │
                          ▼
                    [R90 30kΩ 上拉至 48V]
                          │
                    Q6(SUD50P10 P-MOS) Gate
                    Q6 Source ── 48V
                    Q6 Drain  ── 风扇 Pwr_FAN（+48V 侧）
                          │
                    D10(SS310) 续流二极管
                    D100(MMSZ5245B) Zener 钳位保护（Gate-Source）
                    U24(SMAJ58A) TVS 保护（输出侧）

STM32 PB9(FAN_PWM, pin 46) ───────────────▶ CN3 PWM（风扇调速信号）
```

### 风扇接口信号（CN3）

| 信号 | 方向 | 说明 |
|------|------|------|
| FAN+ | 输出 | 48V 高边（Q6 Drain） |
| FAN- | 输出 | 风扇回路 GND |
| PWM | 输出 | STM32 FAN_PWM → 调速 PWM |
| FG | 输入 | 风扇转速反馈，接 STM32 CAPTURE_PIN（PA8，pin 29） |

> **FG 信号处理**：CAPTURE_PIN 经光耦隔离后进入 STM32 输入捕获，支持最高 100 kHz。

## 11. 模拟量采集电路

两路压力信号采集电路结构相同，以 LM224 运放缓冲后接入 STM32 ADC。

### 11.1 AD1 — 进氢压力（氢瓶压力）

| 器件 | 参数 | 作用 |
|------|------|------|
| L2 | 10 uH | 输入端 EMI 滤波电感 |
| R21 | 60 Ω | 串联阻尼 |
| C23 | 0.1 uF | 输入旁路 |
| R22 | 100 kΩ | 分压/限流 |
| C24 | 0.01 uF | 高频旁路 |
| D2 | PESD5V0S1BA | 输入 TVS 保护（5V 钳位） |
| R37 | 47 kΩ | 运放同相端输入分压 |
| R38 | 47 kΩ | 运放反相端反馈 |
| C33 | — | 低通滤波 |
| C34 | — | 低通滤波 |
| R35 | 200 Ω | 输出串联阻尼 |
| R41 | 18 kΩ | 输出分压（调整满量程至 ADC 输入范围） |
| R44 | 35 kΩ | 输出分压下拉 |
| U9A | LM224 | 电压跟随/缓冲 |

**STM32 连接**：`AD1` → `PA1`（pin 11）

### 11.2 AD2 — 氢瓶压力

结构与 AD1 完全对称，运放型号 `U12A`（LM224）。

| 关键器件 | 参数 |

## 12. 温度采集电路

两路 NTC 热敏电阻分压采集，结构相同。

### 电路结构（以 NTC1 为例）

```
3.3V
 │
R96（10kΩ 精密）
 │
 ├──────── ADC 输入（NTC1 → STM32 PA7，pin 17）
 │
NTC1（10kΩ @ 25℃，外接热敏电阻）
 │
GND
```

| 器件 | 参数 | 说明 |
|------|------|------|
| R96 | 10 kΩ 精密 | NTC1 分压上拉（电堆温度） |
| C61 | 100 nF | ADC 输入低通滤波 |
| R97 | 10 kΩ 精密 | NTC2 分压上拉（环境温度） |
| C62 | 100 nF | ADC 输入低通滤波 |

| 信号 | STM32 引脚 | 采集目标 |
|------|-----------|---------|
| NTC1 | PA7（pin 17） | 电堆温度 |
| NTC2 | PB1（pin 19） | 环境温度 |

> **NTC 参数**：默认优化 10kΩ @ 25℃，可按实际热敏器件型号调整 R96/R97 阻值以提高精度。

## 13. ACC 唤醒与硬件开关

### 13.1 ACC 高有效唤醒电路

**功能**：30~50V 高电平 → 唤醒 MCU；0V → 关机

```
ACC_IN（30~50V）
    │
    ├── R102（100kΩ）── GND（分压限流）
    │
    └── R106（180kΩ）─┬── Q8（AO3400 N-MOS）Gate
                      │       │
                R107(10kΩ)   Drain ── R108(10kΩ) ── 3.3V
                      │       │
                     GND    Source
                              │
                           D101(MMSZ5245B Zener)
                              │
                   Q7(AO3400) ─── ACC_WAKE ──▶ STM32 PA0-WKUP（pin 10）
                              │
                    D15(PESD3V3L1BA) TVS 保护（3.3V 钳位）
```

### 13.2 硬件开关电路

**功能**：短路有效（低有效），按下接 GND

| 器件 | 型号 | 说明 |
|------|------|------|
| U23 | 轻触开关 6×6×5mm（无声/贴片） | 软硬件开关按键 |
| R101 | 10 kΩ | KEY 上拉至 3.3V |
| R105 | 1.01 kΩ | 限流保护 |
| CN4 | XH2.54-2P | 外部 ACC 输入接口（两芯：ACC_IN，GND） |

**STM32 连接**：`KEY` → `PB10`（pin 21，EXTI 外部中断）  
**ACC_WAKE** → `PB11`（pin 22，WKUP/外部唤醒信号输入）
