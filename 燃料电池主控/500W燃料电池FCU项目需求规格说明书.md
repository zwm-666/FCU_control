## 1. 项目概述

### 1.1 背景与目的

本项目旨在为 500W 氢燃料电池电堆开发一套完整的电源管理解决方案，集成 DC-DC 升压转换器（DCF）、辅助电源（DCL）及燃料电池控制单元（FCU）于一体。该设备负责燃料电池系统的能量调度、外设驱动及实时监控，是氢能动力系统的核心控制枢纽。

### 1.2 产品系统架构

系统由三个主要功能模块组成：

- **DCF（主功率 DCDC）**：升压型 DC/DC 变换器，最大输入功率 500W，将燃料电池输出（约 13~16V）升压至 48V 平台，为锂电池组及负载供电。
- **DCL（辅助 DCDC）**：从 48V 母线降压至 12V/10A，为 FCU 外设、阀体驱动及传感器供电。
- **FCU（燃料电池控制单元）**：以 STM32F103C8T6 为主控，集成温度/压力采集、阀体驱动、风扇控制、CAN/RS485 通信及钥匙唤醒等功能，实现燃料电池系统的智能化管理。

## 4. FCU（燃料电池控制单元）功能需求

### 4.1 主控处理器

| 参数 | 规格 |
|------|------|
| 控制器型号 | STM32F103C8T6 |
| CPU 主频 | 72 MHz |
| Flash 存储 | 64 KB（程序） |
| RAM | 20 KB |
| 工作电压 | 3.3V（内核），5V 容忍 I/O |
| 系统待机功耗 | 48V 母线下 2 mA |
| 外部晶振 | 8 MHz（原理图 X1） |
| 外部 EEPROM | 24C02C（I2C 接口，512 字节非易失存储） |

### 4.2 风扇驱动需求

- 支持 **3 线**及 **4 线**风扇，最大驱动电流 **3A**
- 供电电源：**48V 母线**（锂电池输出）
- PWM 转速控制，占空比可调
- 转速反馈检测：支持 FG 信号，最高频率 **100 kHz**
- 驱动芯片：SUD50P10-43L-TP（Q6，P-MOS 高边开关），通过 TLP181 光耦（U18）隔离控制
- 引脚映射（主控板.pdf 复核）：**PB9 = FAN_PWM（调速 PWM）**，**PB8 = MOUT3（风扇电源高边控制）**

### 4.3 高边驱动需求（阀体控制）

| 通道 | 功能 | 供电电平 | 最大电流 | 控制方式 |
|------|------|----------|----------|----------|
| 高边驱动 1（MOUT1） | 进氢阀控制 | 24V（DCL 输出） | 2A | GPIO / PWM，TLP181 光耦隔离 |
| 高边驱动 2（MOUT2） | 排氢阀控制 | 24V（DCL 输出） | 2A | GPIO / PWM，TLP181 光耦隔离 |
| 高边驱动 3（MOUT3） | 风扇电源高边控制（无独立加热膜驱动） | 24V（DCL 输出） | 2A | GPIO / PWM，TLP181 光耦隔离 |

> 驱动器件：IRFR5305（P-MOS），续流二极管 SS36，过压保护 TVS 管。
> 引脚映射（主控板.pdf 复核）：MOUT1=PA0，MOUT2=PA1，MOUT3=PB8。

## 8. 软件功能需求

### 8.1 系统初始化

- 上电后完成时钟配置（72MHz PLL）、GPIO、ADC、TIM、USART、CAN、I2C 外设初始化
- 从 EEPROM（24C02）读取系统配置参数（保护阈值、CAN ID、波特率等）
- 初始化完成后等待 ACC 或 KEY 唤醒信号

### 8.2 控制策略需求

- **DCF 控制**：实现输入侧恒流控制（闭环 PID），输出侧限压保护
- **FCU 状态机**：实现燃料电池启动、运行、停机、故障等状态管理
- **风扇 PWM 控制**：根据电堆温度（NTC1）动态调节风扇转速
- **阀体控制**：进/排氢阀支持 GPIO 模式（开关）和 PWM 模式（脉冲吹扫）

### 8.3 故障检测与保护

- **过温保护**：NTC1/NTC2 温度超阈值时触发紧急停机
- **过压/欠压保护**：输入/输出电压异常时关断 DCF
- **过流保护**：输入/输出电流超限时限流或关断
- **阀体驱动过流检测**：高边驱动电流超过 2A 时关断对应通道
- **CAN 通信超时检测**：超时未收到指令触发安全停机

### 8.4 通信协议需求

#### 8.4.1 CAN 通信

- 默认波特率：**250 kbps**
- 协议帧格式：标准帧（11-bit ID），具体 ID 分配及数据帧定义需双方确认
- **上报数据**：电堆温度、环境温度、进氢压力、氢瓶压力、运行状态、故障码等
- **接收指令**：启停控制、目标电流设定、参数配置等

#### 8.4.2 RS485 通信

- 默认波特率：**9600 bps**
- 协议格式：Modbus RTU 或自定义协议（双方确认）

### 8.5 数据存储需求

- EEPROM（24C02，512B）存储：系统配置参数、故障记录、运行累计时长
- **掉电保护**：关键参数在每次修改后立即写入 EEPROM
