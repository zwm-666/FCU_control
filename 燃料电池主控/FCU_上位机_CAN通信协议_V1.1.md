## FCU_1 — 状态与心跳 `ID = 0x18FF01F0`

**方向**：FCU → 上位机　**周期**：100 ms

### 帧结构

| Byte | Bit | 信号名称 | 说明 |
|------|-----|----------|------|
| 0 | 7:0 | 心跳计数 | 每 100ms 加 1，范围 0~255，翻转周期 25.5s |
| 1 | 1:0 | 系统状态 | `00`=关机　`01`=启动　`10`=运行　`11`=故障 |
| 1 | 3:2 | 故障等级 | `01`=一般故障　`10`=严重故障　`11`=紧急故障 |
| 1 | 7:4 | 预留 | 发送 0 |
| 2~7 | — | 预留 | 发送 0 |

### 状态枚举

```
系统状态 (Byte1 bit[1:0])
  0b00 → 关机
  0b01 → 启动中
  0b10 → 正常运行
  0b11 → 故障

故障等级 (Byte1 bit[3:2])
  0b01 → 一般故障（可继续运行）
  0b10 → 严重故障（需停机）
  0b11 → 紧急故障（立即锁死）
```

## FCU_2 — 电压电流数据 `ID = 0x18FF02F0`

**方向**：FCU → 上位机　**周期**：100 ms

> 硬件来源：电堆电压/电流由主控板 AD1（PA2）、AD2（PA3）采集；DCF 输出电压/电流由 DC-DC 板 INA199（U2/U3）经 IN_I / OUT_I 信号送入 FCU ADC。

### 帧结构

| Byte | 信号名称 | 字节数 |
|------|----------|--------|
| 0~1 | 电堆输出电压 | 2 |
| 2~3 | 电堆输出电流 | 2 |
| 4~5 | DCF 输出电压 | 2 |
| 6~7 | DCF 输出电流 | 2 |

### 信号定义

| 信号名称 | 数据类型 | 比例因子 | 偏移量 | 范围 | 单位 | 硬件来源 |
|----------|----------|----------|--------|------|------|---------|
| 电堆输出电压 | uint16 | 0.01 | 0 | 0 ~ 60 | V | AD1 → PA2（ADC1_IN2） |
| 电堆输出电流 | uint16 | 0.1 | 0 | 0 ~ 50 | A | AD2 → PA3（ADC1_IN3） |
| DCF 输出电压 | uint16 | 0.01 | 0 | 0 ~ 65 | V | OUT_V（DC-DC板分压） |
| DCF 输出电流 | uint16 | 0.1 | 0 | 0 ~ 50 | A | OUT_I（U3 INA199 采样） |

### 解码公式

```
物理值 = 原始值 × 比例因子 + 偏移量

示例：
  电堆电压原始值 0x0BB8 (3000) → 3000 × 0.01 = 30.00 V
  电堆电流原始值 0x00F0 (240)  → 240  × 0.1  = 24.0 A
```

## FCU_3 — 温度与压力数据 `ID = 0x18FF03F0`

**方向**：FCU → 上位机　**周期**：100 ms

> 硬件来源：NTC1（PB0）采集电堆温度，NTC2（PB1）采集环境温度；AD1（PA2）采集进氢压力，AD2（PA3）采集氢瓶压力。

### 帧结构

| Byte | 信号名称 | 字节数 |
|------|----------|--------|
| 0~1 | 电堆温度 | 2 |
| 2~3 | 氢瓶压力 | 2 |
| 4~5 | 进氢压力 | 2 |
| 6 | 氢气浓度 H₂ | 1 |
| 7 | 预留 | 1 |

### 信号定义

| 信号名称 | 数据类型 | 比例因子 | 偏移量 | 范围 | 单位 | 硬件来源 |
|----------|----------|----------|--------|------|------|---------|
| 电堆温度 | int16 | 0.1 | -40 | -40 ~ 150 | ℃ | NTC1 → PB0（ADC1_IN8） |
| 氢瓶压力 | uint16 | 0.01 | 0 | 0 ~ 35 | MPa | AD2 → PA3（ADC1_IN3） |
| 进氢压力 | uint16 | 0.01 | 0 | 0 ~ 2.55 | MPa | AD1 → PA2（ADC1_IN2） |
| 氢气浓度 H₂ | uint8 | 0.5 | 0 | 0 ~ 100 | %vol | 外部氢浓度传感器 |

> ⚠️ **V1.1 修订**：进氢压力数据类型由原 `uint8` 更正为 `uint16`（与帧结构 byte4~5 共 2 字节一致）。

### 解码公式

```
物理值 = 原始值 × 比例因子 + 偏移量

示例：
  电堆温度原始值 0x02BC (700)  → 700  × 0.1 + (-40) = 30.0 ℃
  氢瓶压力原始值 0x0D48 (3400) → 3400 × 0.01 = 34.00 MPa
  进氢压力原始值 0x00FF (255)  → 255  × 0.01 = 2.55 MPa
  氢浓度原始值   0x04 (4)      → 4    × 0.5  = 2.0 %vol
```

## FCU_4 — 外设状态与故障码 `ID = 0x18FF04F0`

**方向**：FCU → 上位机　**周期**：100 ms

> 硬件来源：进氢阀 → MOUT1（PA0）；排氢阀 → MOUT2（PA1）；风扇电源高边控制 → MOUT3（PB8）；风扇调速 PWM → FAN_PWM（PB9）。  
> ⚠️ **主控板原理图仅有一路风扇（Q6，48V，FAN_PWM 控制）**，不存在第二路风扇硬件，原协议中"风扇 2（DCF）"字段已更正为预留。

### 帧结构

| Byte | Bit | 信号名称 | 说明 |
|------|-----|----------|------|
| 0 | 0 | 进氢阀状态 | `0`=关闭　`1`=打开　← MOUT1（PA0） |
| 0 | 1 | 排氢阀状态 | `0`=关闭　`1`=打开　← MOUT2（PA1） |
| 0 | 2 | 风扇电源高边状态 | `0`=关闭　`1`=打开　← MOUT3（PB8） |
| 0 | 3 | 风扇状态 | `0`=停止　`1`=运行　← FAN_PWM（PB9）+ MOUT3（PB8） |
| 0 | 7:4 | 预留 | 发送 0 |
| 1 | 7:0 | 风扇 PWM 占空比 | uint8，1%/bit，范围 0~100% |
| 2~3 | — | DCF MOS 温度 | int16，见信号定义 |
| 4~5 | — | 故障码 | uint16，见故障码总表 |
| 6~7 | — | 预留 | 发送 0 |

### 信号定义

| 信号名称 | 数据类型 | 比例因子 | 偏移量 | 范围 | 单位 |
|----------|----------|----------|--------|------|------|
| 风扇 PWM 占空比 | uint8 | 1 | 0 | 0 ~ 100 | % |
| DCF MOS 温度 | int16 | 0.1 | -40 | -40 ~ 150 | ℃ |

## 上位机_1 — 控制指令 `ID = 0x18FF10A0`

**方向**：上位机 → FCU　**周期**：100 ms

> 硬件对应：进/排氢阀强制控制 → MOUT1/MOUT2（TLP181 光耦 → IRFR5305 P-MOS）；风扇电源高边控制 → MOUT3；风扇调速 → FAN_PWM；DCF 电压/电流目标值 → FCU 通过 POWER_PWM 调节 DC-DC 板控制器。

### 帧结构

| Byte | Bit | 信号名称 | 说明 |
|------|-----|----------|------|
| 0 | 1:0 | 工作模式 | `0`=手动　`1`=自动　其它预留 |
| 0 | 3:2 | 状态控制命令 | `0`=无　`1`=启动　`2`=复位　`3`=急停　`4`=关机 |
| 0 | 7:4 | 预留 | 发送 0 |
| 1 | 0 | 进氢阀强制控制 | `0`=关闭　`1`=开启　→ MOUT1（PA0） |
| 1 | 1 | 排氢阀强制控制 | `0`=关闭　`1`=开启　→ MOUT2（PA1） |
| 1 | 2 | 风扇电源高边强制控制 | `0`=关闭　`1`=开启　→ MOUT3（PB8） |
| 1 | 3 | 风扇强制控制 | `0`=关闭　`1`=按设定转速运行　→ FAN_PWM（PB9） |
| 1 | 7:4 | 预留 | 发送 0 |
| 2 | 7:0 | 风扇目标 PWM | uint8，1%/bit，0~100% |
| 3 | 7:0 | DCF 输出目标电压低 8 位 | — |
| 4 | 7:0 | DCF 输出目标电压高 8 位 | — |
| 5~6 | — | DCF 输出目标电流 | uint16，见信号定义 |
| 7 | — | 预留 | 发送 0 |

### 信号定义

| 信号名称 | 数据类型 | 比例因子 | 偏移量 | 范围 | 单位 |
|----------|----------|----------|--------|------|------|
| 风扇目标 PWM | uint8 | 1 | 0 | 0 ~ 100 | % |
| DCF 输出目标电压 | uint16 | 0.1 | 0 | 0 ~ 65 | V |
| DCF 输出目标电流 | uint16 | 0.1 | 0 | 0 ~ 20 | A |

### 编码公式

```
原始值 = (物理值 - 偏移量) / 比例因子

示例：
  设置 DCF 电压 48.0V → (48.0 - 0) / 0.1 = 480 = 0x01E0
    Byte3 = 0xE0（低8位），Byte4 = 0x01（高8位）

  设置 DCF 电流 10.0A → (10.0 - 0) / 0.1 = 100 = 0x0064
    Byte5 = 0x64，Byte6 = 0x00
```

### 状态控制命令说明

```
Byte0 bit[3:2]
  0b00 → 无操作（保持当前状态）
  0b01 → 启动
  0b10 → 复位（清除故障，重新初始化）
  0b11 → 急停
  0b100 → 关机
```

## 故障码总表

> 对应 FCU_4 帧 Byte4~5 的故障码字段。

### DCF 故障（0x00~0x0F）

| 故障码 | 故障名称 | 故障等级 | 处理建议 |
|--------|----------|----------|----------|
| `0x00` | 系统正常 | 0 = 正常 | — |
| `0x01` | 输入欠压故障 | 2 = 严重 | 停机 |
| `0x02` | 输入过压故障 | 2 = 严重 | 停机 |
| `0x03` | 输入过流故障 | 3 = 紧急 | 锁死 |
| `0x04` | 输出欠压故障 | 1/2 = 一般/严重 | 视幅度决定限流或停机 |
| `0x05` | 输出过压故障 | 2 = 严重 | 停机 |
| `0x06` | 输出过流故障 | 1 = 一般 | 限流 / 打嗝 |
| `0x07` | DCF 内部过温 | 2 = 严重 | 降载或停机 |

### FCU 故障（0x10~0x1F）

| 故障码 | 故障名称 | 故障等级 | 处理建议 |
|--------|----------|----------|----------|
| `0x10` | 电堆过温故障 | 2 = 严重 | 停机（NTC1 超阈值） |
| `0x11` | 氢气浓度高（泄漏） | 3 = 紧急 | 立即切断氢气阀（MOUT1） |
| `0x12` | 进氢压力异常（高/低） | 2 = 严重 | 停机（AD1 异常） |
| `0x13` | CAN 通信超时 | 1 = 一般 | 维持或停机 |
| `0x14` | 急停触发 | 3 = 紧急 | 立即停机并保持故障锁定 |

### 外设故障（0x20~0x2F）

| 故障码 | 故障名称 | 故障等级 | 处理建议 |
|--------|----------|----------|----------|
| `0x20` | 风扇堵转/开路 | 1 = 一般 | 报警，降额运行（FG 反馈异常） |

> ⚠️ **V1.1 修订**：原 `0x21`（风扇 2 堵转/开路）已删除，主控板硬件仅有一路风扇（Q6，48V，FAN_PWM）。

### 故障等级说明

| 等级值 | 等级名称 | 对应 FCU_1 故障等级字段 | 响应策略 |
|--------|----------|------------------------|----------|
| 0 | 正常 | — | 无 |
| 1 | 一般故障 | `0b01` | 报警，可继续运行或限流 |
| 2 | 严重故障 | `0b10` | 停机，需复位后重启 |
| 3 | 紧急故障 | `0b11` | 立即锁死，需人工干预 |

## 硬件信号对应关系

> 本节说明 CAN 协议信号与主控板（STM32F103C8T6）及 DC-DC 板硬件引脚的完整映射，以原理图为准。

### FCU 上报信号（FCU → 上位机）

| CAN 信号 | 硬件信号 | STM32 引脚 | 外设 / 电路 |
|---------|---------|-----------|------------|
| 电堆输出电压 | AD1 | PA2（ADC1_IN2） | 电堆电压分压采集 |
| 电堆输出电流 | AD2 | PA3（ADC1_IN3） | 电堆电流采样 |
| DCF 输出电压 | OUT_V | 扩展 ADC 通道（待确认） | DC-DC 板分压 → FCU ADC |
| DCF 输出电流 | OUT_I | 扩展 ADC 通道（待确认） | U3 INA199（R18=5mΩ） |
| 电堆温度 | NTC1 | PB0（ADC1_IN8） | 10kΩ NTC 分压（R96） |
| 环境温度 | NTC2 | PB1（ADC1_IN9） | 10kΩ NTC 分压（R97） |
| 氢瓶压力 | AD2 | PA3（ADC1_IN3） | LM224 缓冲（U12A），0.5~4.5V |
| 进氢压力 | AD1 | PA2（ADC1_IN2） | LM224 缓冲（U9A），0.5~4.5V |
| 进氢阀状态 | MOUT1 | PA0（pin 10） | TLP181(U16) → Q3 IRFR5305 → 24V |
| 排氢阀状态 | MOUT2 | PA1（pin 11） | TLP181(U14) → Q1 IRFR5305 → 24V |
| 风扇电源高边状态 | MOUT3 | PB8（pin 45） | TLP181 → Q6 高边控制链路 |
| 风扇状态 | FAN_PWM + MOUT3 | PB9（PWM）+ PB8（高边） | 调速 PWM + 电源高边控制 |
| 风扇 PWM 占空比 | FAN_PWM | PB9 | PWM 占空比直接反映 |
| DCF MOS 温度 | — | 扩展 ADC | DC-DC 板温度传感器（待定） |
| 故障码 | — | 软件内部 | FCU 状态机生成 |

| CAN 信号 | 硬件信号 | STM32 引脚 | 外设 / 电路 |

| 进氢阀强制控制 | MOUT1 | PA0 | TLP181(U16) → Q3 → 进氢阀 |

| DCF 目标电流 | POWER_PWM | 同上 | FCU → DC-DC 板 ILIM |
